# Hourvia V2

Time tracked. Progress made. Sprint 0 by Living IT Solutions.

This new implementation is a frontend-only organizational workspace demo. All data is illustrative; no business mutations, authentication or persistence are active. Hourvia V1 is untouched.

Install with `npm ci`. Local UI: `npm run dev`. Checks: `npm run typecheck`, `npm run lint`, `npm run test`, `npm run check:architecture`. Build script is configured for the platform; no build is executed during this sprint. Never add migrations, connect a database or deploy without separate authorization.

See docs/architecture/overview.md and docs/sprint-0-final-report.md. Dependencies are locked in package-lock.json. Node 22+ is required; platform Node 24 is compatible with the chosen toolchain.
